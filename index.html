2. Introduction to EDU-Revolution

EDU-Revolution is an educational initiative of Lovely Professional University (LPU) designed to extend learning beyond conventional classroom-based education. It focuses on student-centred learning, practical experience, innovation, industry exposure, and recognition of achievements outside the classroom.

According to LPU, EDU-Revolution allows students to customise aspects of their learning and evaluation and participate in activities such as certifications, MOOCs, innovative projects, hackathons, entrepreneurship, competitive examinations, consultancy projects, and social-impact activities. The university uses its digital EDU-Revolution interface to allow students to select activities, submit evidence, and receive academic benefits after verification.

The initiative is significant because it connects academic learning with practical outcomes. LPU describes EDU-Revolution as an approach involving learning beyond the classroom, real-world projects, gamification, industry exposure, and career-oriented development. Its official EDU-Revolution portal also describes a four-step process: selecting a category, choosing a course/track, submitting an achievement, and receiving benefits. Therefore, EDU-Revolution provides students with opportunities to demonstrate knowledge and skills through different forms of learning and achievement rather than depending only on conventional classroom activities.

4.4 Technical Project Architecture: EduMate Arena

The project engineered during the sprint, titled EduMate Arena, is an interactive peer-learning and computer science educational platform designed to streamline algorithmic study and collaboration:

  • Client-Side Layer: Built with semantic HTML5, modern CSS3 styling, and modular Vanilla JavaScript, offering a responsive interface with real-time flashcard testing and algorithmic practice views.
  • Backend Application Layer: Developed using a Node.js runtime environment. Integrated WebSockets to support real-time peer messaging, shared revision timetables, and concurrent room updates.
  • Artificial Intelligence Layer: Integrated Google Gemini API endpoints to provide automated conceptual hints, code error explanations, and dynamic visual mindmap generation.
  • Version Control & Engineering Hygiene: Maintained via GitHub with structured feature branches, systematic code reviews, and transparent commit logs.
