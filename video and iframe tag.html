Video Tag Example

By using attribute like controls, we can add video controls to our video elements.
By using attribute like autoplay, we can make our video play automatically when the page loads.
By using attribute like loop, we can make our video play in a loop.
By using attribute like muted, we can make our video play without sound.
By using attribute like height and width, we can adjust the size of the video.


Iframe Tag Example

By using attribute like src, we can specify the URL of the page to be displayed in the iframe.
By using attribute like width and height, we can adjust the size of the iframe.
By using attribute like frameborder, we can specify whether or not to display a border around the iframe.
By using attribute like allowfullscreen, we can specify whether or not to allow the iframe to be displayed in fullscreen mode.
